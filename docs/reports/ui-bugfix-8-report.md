# 思维链折叠 + 后台生成保活（2026-11-26）

## 1. 思维链折叠（之前确实没做单行折叠）
- 之前的"折叠"只是过程组级折叠；reasoning 行一直整段铺开，内容变长会持续撑高列表，看起来"思考到一半卡住"。
- 现在 reason 行按 DSH 的 ReasoningRow 语义做单行披露：
  - 默认只显示 `▸ 思考 · <首行预览>`（24dp 级，单行省略）；
  - 点行展开完整思考，再点收起；
  - 流式中预览随增量更新，不再整段重建高度。
- 过程组头仍是 stickyHeader：展开长内容时收起按钮吸附在消息区顶部，永远可点。
- 工具行同样单行摘要 + 点开详情。

## 2. 后台断连/保活（高优）
- 生成期间自动启动既有 `MycoForegroundService`（specialUse，refcount），请求结束/失败自动停止；切后台不再被系统冻结杀进程。
- 真机验证：发送 "write a 1000-word essay..." 后立即按 Home，25s 后回到 App，回答完整生成完成（13.4s，1 步），连接未断。
