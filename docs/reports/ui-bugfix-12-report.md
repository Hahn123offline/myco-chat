# 组体滚动严格隔离（2026-11-26）

- 组体（过程/思考展开内容）的 nestedScroll 现在同时拦截 **postScroll 与 fling**：
  - 组内滚动到边界后，同一手势剩余位移不交给外层（撞墙）；
  - 惯性/甩动也不交给外层。
- 真机验证：展开长思考，在组体内部快速上甩（100ms）后，屏幕首项仍是同一组头/思考行，外层消息位置未移动；组体只是自己滚动。
- 备注：严格隔离意味着用户在组体内一路滑到边界后继续滑不会滚外层；需要从组体外区域滑动才能继续浏览（这是"墙"的代价，按你的要求优先保证不飞出）。
- 组内小行 stickyHeader、外层组头不吸顶保持。
- 测试 94 绿。
