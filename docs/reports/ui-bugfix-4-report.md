# UI/模型配置修复批次 4（2026-11-26）

## 1. 修复

### Provider/模型配置 GUI 卡死
- 原实现是 AlertDialog + 固定 420dp 高度的滚动列，模型目录下半部分/保存按钮在真机上点不到也滑不动。
- 改为 **全屏 Dialog（占屏 92%）**：标题固定，内容区 weight(1f) 纵向滚动，底部固定「取消/保存」；模型目录所有字段、思考强度、添加模型都能滚到并点击。
- 真机验证：打开「编辑 deepseek」可滚动到模型 ID/上下文/最大输出/支持思考强度/添加模型/保存。

### 重新生成的分叉与闪烁
- 点击重新生成时立即把视图切到**父节点（分叉点）**，旧分支不再显示在新回答下面；完成后再由 reload 切到新回答。
- 新增单测：对第二轮回答重新生成时，请求上下文严格为 `Q1, A1, Q2`，**不含旧 A2**；用户已撤回“模型带旧链内容”的 100% 结论，但数据层测试证明上下文是对的。
- 已知：模型自身抖动/幻觉不归代码问题。

### 思考/工具实时交错
- 实时时间线里，`ToolStarted`/首个文本 delta 会把当前思考行标记结束；下一条 reasoning 会新建一行，不会继续追加到旧思考下面 → 工具与思考按时间交错。
- 完成后从事件日志重建同序时间线。

### 回到底部
- `scrollToItem(last)` 只对齐"最后一条的起始位置"；改为 `scrollToItem(last, 100000)`，会滚到该 item 的实际底部。自动跟随与「↓ 回到最新」都走这个逻辑。

### Markdown `---`
- 新增分隔线语法：`---/***/___` 渲染 `HorizontalDivider`。

### 搜索来源与链接
- `web_search` 结果 JSON 里解析 `results[].title/url/site`，在工具行下渲染**可点击来源卡片**（最多 6 条），点击用系统浏览器打开。
- Markdown 链接改为 `LinkAnnotation.Url`，正文中的 `[text](url)` 可直接点开。
- 这是 DSH demo 展示链路的第一版；正文编号引用/悬浮预览还没做。

### DeepSeek 思考强度
- Provider 模型编辑器现在可开启「支持思考强度」、设置默认档位和高/中/低 API 参数值。
- Anthropic 方言支持数字预算，并对字符串档位做默认映射：low=2048 / medium=8192 / high=32768 budget_tokens。
- 现有 deepseek-flash provider 仍需在编辑器里手动开启思考强度（默认 high + 对应参数）。
