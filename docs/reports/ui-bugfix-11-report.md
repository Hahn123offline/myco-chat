# 组内小行吸顶 + 外层不吸顶 + 滚动隔离（2026-11-26）

按确认的三点实现：
1. 外层「思考过程」组头**不再吸顶**，只是普通内容，会跟随消息滚走。
2. 组体内部改成嵌套滚动列表：每个小思考/工具行是 stickyHeader，展开其内容时该小行吸在**组体滚动视口顶部**，滚到下一行时被下一行顶替；组体高度上限仍 min(400dp,50vh)。
3. 组体滚动加 `nestedScroll` 隔离：组体内滚动到边界时，本次手势**不会把 fling/惯性传递到外层消息列表**；下一次手势才可滚外层。
- 其它：工具/思考行单行摘要、点开详情；展开组时自动把组头滚到消息区顶部，保证组体可见。
- 真机：展开组后外层头随内容下移（不再钉窗口）；展开小思考行可显示全文且行头在组体顶部；无崩溃。
- 测试 94 绿。
