# 组体边界拖动交给外层原生滚动（消除双系统竞争）（2026-11-26）

上一版到边界后我们从组体手工 `dispatchRawDelta` 给外层，与外层自己的滚动同时存在，导致边界拖动卡顿。
现在：
- 手势起点在组体内部、且组体还能滚 → 组体自己消费（内部衰减 fling），外层完全收不到；
- 手势起点在组体边界 → 组体**完全不消费**，直接交给外层 LazyColumn 原生滚动（包括原生 fling），不再手工分发。
- 组体 `userScrollEnabled=false` 只影响组体内部 LazyColumn，不阻止外层原生手势。
- 同时去掉了滚动时 `atBottom` derivedState 引发的整棵聊天树重组（这是另一处掉帧源）；fling 改为 `withFrameNanos` 帧同步。
- 真机：组体到边界后再次拖动，外层正常滚动，不再出现"手在组体内拖动、外圈两套逻辑抢事件"的卡顿。
- 组内小行吸顶、外层组头不吸顶、严格不飞出的语义保持。
