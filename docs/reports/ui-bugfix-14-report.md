# 组体滚动手势接管（2026-11-26）

彻底改法：不再依赖 nestedScroll 的 fling 传递，组体自己接管手势。
- 组体内 LazyColumn 设置 userScrollEnabled=false；
- 组体 Box 的 pointerInput 在每次手势开始时判断方向：
  - 手指方向还能滚组体 → 本次手势的所有位移/惯性都由组体内部消费（自带衰减 fling），**绝不交给外层**；
  - 手势开始时组体已在该方向边界 → 完全不消费，让外层消息列表接管（这正是"靠边还拉"的新手势）。
- 因此：
  - 从中间开始滑、滑到边界：撞墙停住，外层不动；
  - 到边界后**新的**一次手势：外层滚动。
- 真机验证：
  1) 第一次上甩：组体内部滚动，外层首项不变；
  2) 组体到底后第二次新手势：外层开始滚动，组头离开屏幕。
- 组内小行 stickyHeader、外层组头不吸顶保持。
