# 折叠动画、展开不动窗、平滑自动滚动（2026-11-26）

1. 折叠动画
- 过程组体用 `AnimatedVisibility`（expandVertically + fadeIn / shrinkVertically + fadeOut）展开/收起，不再瞬间跳变。
- 动画只影响组体自身高度，不主动改滚动坐标。

2. 展开时绝对不动窗口坐标
- 删除了"展开过程组时自动 scrollToItem 到组头"的逻辑；点击外层/内层展开只改变内容，不调整列表位置。
- 真机验证：在消息中部点开"思考过程"，首屏内容位置保持不变（展开内容在原位出现）。

3. 平滑自动滚动
- 流式跟底不再每 60ms 瞬间 scrollToItem；改为每帧（withFrameNanos）按距离底部溢出量的 35%（1–64px/帧）平滑推进。
- 用户上滑仍立即停止跟随；回到底部恢复；不会抢用户窗口。
- 同时保留之前：组体内滚动、折叠头吸顶、边界手势交还外层原生滚动。

4. 待验
- 折叠动画时长使用默认（约 200ms），如觉得快/慢可调。
- 流式平滑的实际手感需要连续发长回答确认。
- 测试 94 绿。
