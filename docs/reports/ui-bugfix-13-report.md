# 组体滚动手势代际（2026-11-26）

按澄清实现：
- 手势开始时组体**没到边**：本次手势全部滚组体；滚到边界后剩余位移/惯性撞墙，不外溢。
- 手势开始时组体**已经在该方向边界**：这是一次"我要往外滚"的新手势，外层立即接管。
- 惯性只在"从内部滚出来"时被吞掉；新手势起于边界时允许外层滚动/惯性。
- 实现：`GroupBodyScrollIsolation` 记录每次手势起点的可滚动方向 + `pointerInput` 的 gesture down/up 生命周期。
- 真机验证：展开长思考后
  1) 第一次快速上甩：组体内容滚动，外层位置不变；
  2) 到达组体底部后，第二次新手势上甩：外层消息开始滚动，组头离开屏幕。
- 组内小行 stickyHeader、外层头不吸顶保持；测试 94 绿。
