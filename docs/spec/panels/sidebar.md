## 0. 一句话 + 范围

**一句话**：`sidebar` 面板 = 会话的**导航面**：它把「会话元数据列表（置顶区 + 时间四档分组 + 每组配额）」渲染成抽屉（`<840`，覆盖 route）或常驻列（`≥840`），并在其上提供新建会话、会话搜索、行级操作（置顶/改名/归档/删除）与软删撤销，同时承载归档/回收站列表本体（入口归 `settings`）。

**负责**：
1. 抽屉**内容**：头部（标题/搜索键/新建键）、列表（分组/配额/空态/加载/失败）、底部设置入口；
2. 会话行全交互：单击打开、长按开菜单、行尾 `⋯`、选中态、运行态点、空白草稿行特例；
3. 行菜单 4 项与三个浮层（菜单 sheet / 改名 Modal / 删除确认 Modal）+ 软删撤销 Snackbar；
4. 搜索：入口、250ms 防抖、结果行与高亮、点击定位、三态、退出；
5. 归档 / 回收站列表本体（两个全屏 route 视图，`view=archived|deleted`）；
6. 宽屏常驻列 / rail 的**内容**（列宽/列态归 `base.layout.sidebar-column`）；
7. 会话列表的读屏语义契约（`sidebar.a11y.keyboard`）。

**不负责**（归邻面板，本文件只引用不定义）：
- 抽屉 route 本体、宽度、遮罩、开合手势、返回 dispatcher、预测式返回、保活/冻结、insets、宽屏列宽/列态、覆盖即隔离 → `base.layout`（`BL-*`）；
- 菜单/Modal/Snackbar 的原子契约（关闭集合、焦点陷阱、时长、命中区） → `base.primitives`（`BP-*`；菜单手机形态 = BottomSheet 单层列表，`BP §3.12`、`BP-33`；Snackbar 走 `base.primitives.toast`，`BP-36…BP-39`）；
- 顶栏槽位与顶栏其它键 → 壳（`BL`；本面板只提供「菜单键」这一颗的行为与尺寸）；
- 会话内容、流式、滚动跟随 → `chat`；输入区 → `composer`；`settings` 的「会话数据」入口（归档/回收站入口归它，本体归本面板，`p2/sidebar.md:94`、`M6:167`）；
- 右栏 `base.sidebar-right` → **首版不启用**（Q-SB-12=B，`BL-51`）。

**明确不做（P2 §4 共 26 条，这里只留一行摘要，实现时不得"顺手做了"）**：工作区分组/工作区菜单/添加工作区/未分组桶；组头折叠/组内新建；fork；文件夹分组/bot 隐藏/项目与远程分区；状态筛选胶囊/安全模式横幅/工作区切换；右栏 quick-panel 与会话详情；底部导航瓦片；视图选项菜单（分组/排序/归档三档）；hover 悬浮卡 + 标题跑马灯 + 双击标题改名 + 行尾双悬浮键；会话拖拽排序；归档三档筛选；收起态浮组；未读/待确认状态点；**批量选择（P3 收口：首版不做，见 §5.2 P3-SB-06）**；**搜索快捷键（与 D-09 冲突，见 §5.2 P3-SB-02）**；身份区/环境文案；搜索「查看归档」动作。

#### 1.1.1 宽度公式（三档 + 哪个因子真正 binding）

`Wdrawer = min(320 + startInset, 0.86×W, W − 56)`（`<840`；`MEDIUM` 打开时的覆盖抽屉同式）。

- **`0.86×W` 在现役手机尺寸上不 binding**：`0.86W < W−56` ⇔ `W > 400`，而 `W > 400` 时 `0.86W > 344 ≥ 320+startInset` → 恒被 320(±inset) 压住；`W ≤ 400` 时 `0.86W ≥ W−56` → 恒被 `W−56` 压住。**保留该因子作为超宽/未来 inset 变化的防御项**（SB-01 真机三档量测确认，不做删项）。
- **`startInset` 会改变收口项**：`startInset = 0` 时 `W<376 → W−56`，`W≥376 → 320`；`startInset=24` 时 `W=390` 得 `min(344, 335.4, 334)=334`（内容宽 310）。→ 内容布局**不得依赖 320 这个具体值**，只能依赖「内容宽 = 抽屉宽 − startInset」。
- `≥840` 列宽固定 280 / 56 / 0，与屏宽无关；`MEDIUM` 的覆盖抽屉仍按上式（`BL-36`）。

#### 1.1.2 关闭路径集合（本面板视角）

| 路径 | 归属 | 触发条件 | 本面板义务 |
|---|---|---|---|
| 系统返回 / 预测式返回 | BL | dispatcher 第 3 级 `pop` | 浮层开着时先关浮层（登记到 dispatcher） |
| 点遮罩 | BL | 按下+松手都在遮罩（G-18） | 无 |
| 从进入边拖出 | BL | ≥22%W 或末速度 ≥600dp/s | 拖拽期列表不吃横向手势 |
| 导航后自动收 | **本面板** | 点会话行 / 新建 / 设置 | 500ms 防连关 + 60ms 延迟 + 同帧 pop |
| 点入口键 | 本面板 | `<840`：开抽屉（关走返回/遮罩/拖出）；`≥840`：列态 280↔56↔0 切换（**不是 pop**） | 键语义随窗口类/列态切换（§3.1） |
| 不存在的路径 | — | **不得**用「上滑关闭」「点标题关闭」「Escape 关闭抽屉（无键盘）」 | 反证：多一条关闭通道 = 返回链多一个仲裁点 |

#### 1.1.3 面板内浮层登记清单（供 dispatcher）

| 浮层 | 家族 / z | 打开时返回键行为 | 关闭后 |
|---|---|---|---|
| `sidebar.session.menu`（行菜单） | menu / 1100（手机 = BottomSheet 单层列表，`BP §3.12`） | 只关菜单，抽屉不动 | 回到打开它的行、焦点回 `⋯` |
| `sidebar.session.rename`（改名 Modal） | modal / 1000 | 只关 Modal（脏检查：有改动 → 先二次确认，见 §3.13） | 回原行；失败不关 |
| `sidebar.session.delete-confirm`（删除确认 Modal） | modal / 1000 | **pending 期间不关**（关不掉也不阻塞提交，见 §3.14） | 成功 → 行移除 + Snackbar |
| `sidebar.undo.toast`（Snackbar） | toast（`shell.overlay`，20） | **不消费返回**（`BP-39`） | 6s 自动过期或点动作 |

> 互斥规则：同刻最多 1 个浮层；菜单 → Modal 切换必须**先关菜单**再开 Modal（我方取值（P4 校准）：多浮层叠放要给 dispatcher 排 4 层优先级且每层单独遮罩，收益为零、失败面翻倍）。
