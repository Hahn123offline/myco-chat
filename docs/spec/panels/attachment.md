## 0. 一句话 + 范围

**一句话**：`attachment` 负责「把外部媒体/文件变成一条可发送的附件」以及「把历史消息里的附件显示出来」——**首版**：点 `+` 打开 **BottomSheet 三入口（拍照 / 相册 / 文件）**，点入口先关 sheet 再起对应**系统 picker**，选中的文件经 **intake 校验（整批拒绝）** 后进入附件项**三态状态机**（处理中 → 就绪 / 失败，本地落盘），处理中或存在失败项时**阻止发送**；历史消息图片走**应用内全屏查看器**、通用文件走**信息卡**；移除/删除后的文件按**孤儿清理**（M-03）处理。**候选（`[candidate]`，不进首版门禁）**：输入卡下方**内联面板** + **最近照片条**（4 张横排、圆形选中环、多选/反选）+ **等宽三宫格**来源大按钮。**不画输入区**：`+` 键、草稿附件轨（rail/chip/缩略图/文件卡/移除/重试）的呈现归 `composer`。

### 0.2 负责 / 不负责

**负责**：附件面板（**首版 BottomSheet 三入口**；候选内联 + 照片条 + 三宫格单独路径）；三条来源的取数、取消、失败文案、返回落点；intake 单文件/总量/类型校验与**整批拒绝**文案（**数量首版不设客户端上限**，超限由后端错误回执呈现）；附件项状态机（`处理中/就绪/失败`）与**发送门禁**（处理中禁发、失败项拦发）；处理/保存通道（串行、失败分级、重试、无取消）；历史消息图片（尺寸预算/加载/失败重试/查看器触发/同组横滑）与文件信息卡；移除/替换/删除后的文件生命周期（孤儿清理 M-03）。

**不负责**：输入区布局与主键语义（`composer`，D-14；"处理中/失败项禁发"的门禁**判据**在本文件、**键位呈现**在 composer）；草稿轨视觉（同上）；模型/思考档（`model`）；会话/消息滚动（`chat`）；查看器原语手势（`base.primitives`）；顶栏与 insets 真源（`base.layout`）；审批/提问卡（`approval`）。

### 0.3 明确不做（P2 §4 共 12 条：除"应用内相册网格"已按 D-17=B 转为 `[candidate]` 外，其余 11 条摘要如下，实现时不得"顺手做了"）

桌面级全屏拖放遮罩；显式"取消上传"按钮；轨上竖滚转横滚；扩展名白名单（986 行清单）；上传并发 3 队列；dsh-Go 面板里的插件工具格 / 生成模式 / 「本对话」卡 / 「手机操控」卡；太墟的扩展入口 / 草图抽屉；视频附件（首/尾帧）；长按图片动作菜单（保存/分享/复制/存相册）；DSH「子代理 continuable 只收图片」；引用角标 / 右侧来源面板（归 `chat`）。
