## 0. 一句话 + 范围

**一句话**：`settings` 是 myco 的**配置层唯一写 UI**——D-01 覆盖栈里的一层全屏 route（全宽度均 `FULL` 全屏覆盖；≥840 只做内容区限宽 720 居中，D-29，见 §1.3.1），内含 **5 个子页**（通用 / 模型 / 会话数据 / 关于 / 诊断）+ 一个**不占栈的设置搜索浮层**；它负责 G-12 保存语义（哪些页显式保存、哪些即时写）、脏检查三出口、危险操作确认，以及 provider / 模型目录 / 外观 / 语言 / 内容字号的配置写入；**不含**会话内「模型 × 推理等级」选择（归 `model` 面板），也不含本仓库没有运行时的子页。

### 0.6 术语

- **壳 / 设置层**：`settings.shell.panel`，D-01 栈里 depth1 的一个 route（宽屏仍全屏覆盖，仅内容限宽；D-29）。
- **子页 / section**：5 个之一（general / models / data / about / diagnose），同层切换，**不是** route。
- **浮层（float）**：设置在面板内自己管理的覆盖层；**不进 PanelRoute 栈**，登记到 `base.layout.back.dispatcher` 的「面板内浮层」一级。本面板有 4 类浮层：设置搜索、Provider 编辑层、拉取模型 sheet、确认 Modal。
- **行 / 设置项**：页面内容区里一个可点/可展开的条目，= 一个 13 字段节点；搜索定位以行为单位。
- **anchor**：搜索跳转目标，规则见 §1.5。

### 1.5 `anchorId` 命名规则与搜索注册表（D-20 的落地前提）

#### 1.5.1 规则（可判定）

1. **`anchorId` = 设置项所在行的节点 ID**（如 `settings.general.font-size`）。**一个 anchor 对应页面上一个可滚到、可高亮的行容器**；不复用、不改名（**P4 一旦发布不得改**，否则搜索会跳到旧位置）。
2. **页面锚**：`settings.page.<section>`（`general`/`models`/`data`/`about`/`diagnose`）。仅当查询命中**子页名**时使用，定位 = 页面顶部（不滚动、不高亮行）。
3. **一对多允许**：只在「编辑层内字段」这一类出现——它们没有独立可定位行（必须先选 provider），统一锚到 `settings.models.row`（Provider 列表），结果行标题写「Provider 编辑 · 字段名」。**不许**为编辑层字段发明第二个跳转目标。
4. 每个 anchor 必须：`sectionId` 正确、目标节点存在、可滚动到（在目标子页的滚动内容内）、注册表内唯一。
5. 动态实体（具体 provider、具体模型、具体会话）**不进注册表**（它们没有稳定 anchor）；搜索只覆盖「设置项」本身。

#### 1.6.2 「同页不混用」的可判定证明（SET-27）

| 页单元 | 无什么（证明它只有一种语义） |
|---|---|
| 通用 | **无**文本输入 / URL / 密钥 / 数值输入框；**无**「保存」按钮 → 只能是即时写 |
| 模型 · 列表页 | **无**自由文本输入框（搜索框只在拉取 sheet 内）；**无**「保存」按钮 → 只能是即时写 |

> 反证：若编辑层里塞一个「即时写」的开关（例如「启用该 provider」），用户在同一个浮层里既有"改了就生效"又有"要按保存"的控件，无法预测改动何时落盘——这正是 G-12「同页不许混用」要防的。

### 1.9 设置搜索交互规格（D-20=B）

#### 1.9.1 形态与状态

| 状态 | 进入条件 | 布局 | 可交互项 | 退出 |
|---|---|---|---|---|
| 搜索浮层·空查询 | 点顶栏搜索钮（自动聚焦并弹 IME） | 输入行（无文本）+ 热门词区 | 热门词 chips（点 = 填入并立即检索）；取消 | 取消/返回 → 关浮层回原页 |
| 搜索浮层·有结果 | 查询 trim 后非空且命中 ≥1 | 输入行 + 结果列表（44 行 × N） | 点结果 = 跳转并关浮层；清空钮 = 回空查询；取消 | 同上 |
| 搜索浮层·无匹配 | 查询非空且命中 0 | 输入行 + 「没有找到「q」相关的设置」+ **建议词 chips**（取热门词前 3） | 点建议词 = 换查询；取消 | 同上 |
| 搜索浮层·IME 打开 | 任一状态 | 结果列表高度 = 可视区 − IME；列表可滚到最后一条 | 同上 | 收键盘后保持原状态 |

**布局**：搜索浮层 = 全屏不透明覆盖在设置层之上（**不 push route**，登记为面板内浮层）；顶栏 = 输入框 48 + 右侧「取消」44（文本按钮，宽 ≥64）；内容水平 padding 16；结果行 44。**不做**：旧式「过滤隐藏其它卡片」（D10 缺陷）、跨面板搜索（会话/模型面板各自有搜索）、搜索历史。

#### 1.9.2 匹配规则（可判定）

1. 归一化：`trim` + 转小写；**不**分词、**不**做拼音（首版）。
2. 匹配字段：条目中文名、别名（§1.5.2 表）、子页名；**不**匹��长说明/帮助正文。
3. 排序：`以查询开头的条目名` > `条目名包含` > `别名包含` > `仅子页名命中`；同档按注册表顺序。
4. 子页名命中：显示为页面锚（§1.5.1-2），一行「子页名 · 全部设置」；点击 = 打开该子页顶部。
5. 结果不截断（注册表 <50 条）；若将来 >50：显示前 50 + 「还有 N 条，请细化关键词」。
6. IME 的「搜索」键 = 若结果 ≥1 跳转第一条；0 条无动作（不发提示，避免噪音）。

#### 1.9.3 结果行

```
[子页名 12/18 secondary] · [条目名 14/22 primary，命中片段加粗 + 高亮底色]
```
行高 ≥44、水平 padding 16、整行可点；读屏文本 = 「子页名，条目名」（高亮不改变语义）。

#### 1.9.4 定位配方（点结果后，P4 按此 5 步实现）

1. 关闭搜索浮层（瞬时，无动画）。
2. 切到目标子页（若已在该页且已在该滚动位置，跳过第 3 步）。
3. 目标行**完整可见**（`rowTop ≥ viewportTop+8` 且 `rowBottom ≤ viewportBottom−8`）→ 不滚；否则滚到 `rowTop = viewportTop + 8`（最后一屏不够时滚到底再判定）。
4. 目标行高亮 **2000ms（±100ms）**：底色 = theme 的 highlight token，**瞬时出现/瞬时消失**（不做高度动画，G-10）。
5. 语义：TalkBack 播报「已定位到 <条目名>」，焦点移到目标行容器（不自动激活行内控件）。
6. 页面锚（子页名命中）：只切子页并回到顶部，不高亮行（高亮页标题 2s 可选，**不做**）。

#### 1.9.5 Esc / 返回 / 焦点

- 返回键/侧滑 → 关搜索浮层，回原子页**原滚动位置**（±1dp）；栈深不变。
- 外接键盘 Esc：**不承诺**（D-09 触摸-only；`base.primitives` 也未承诺 Esc 支线）。若实现层顺手接了 `onPreviewKeyEvent`，不得成为唯一出口。
- 关闭搜索后回焦到顶栏搜索钮（`base.primitives.modal` 回焦契约同族）。
