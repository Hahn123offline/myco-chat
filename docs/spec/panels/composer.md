7. **键盘支线按 D-09 砍掉**：候选面板不做 ↑↓/Enter/Esc 绑定、不做 hover 高亮（§3.15 字段 4/11）；触摸端用「列表上下滑 + 点击选中」。

## 0. 一句话 + 范围

**一句话**：`composer` 是对话页底部**参与布局流的固定尾**——把「队列条（本地队列）/ 草稿附件轨 / 多行草稿区 / 工具行（`+`、模型胶囊、主键）/ `/` 本地命令候选面板 / 长文转附件提示」排成一张卡，负责发送与停止的**单键状态机**、草稿与附件轨的**编辑态呈现**、以及把**输入区实时高度同帧发布给 chat 列表**。

**负责**：座位与卡的结构与几何；草稿区（多行镜像撑高、6 行上限、键盘降档、内滚）；主键单键状态机与提交防重入（BUG-004）；工具行座位与键位固定；`+` 的接线（打开 attachment 面板）；草稿附件轨（项高 64、横滚、新增滚末端、移除、重试**入口**、空轨不渲染、高度发布）；粘贴接入点与长文转附件提示；`/` 本地命令候选面板（combobox；**`@` 首版不做**，组件形态保留复用）；**本地队列**（客户端持有、`AssistantDone` 后自动发下一条）与队列条/行/编辑 Dialog；输入区高度 → chat 的发布契约。

**不负责**（归邻面板，本文件只引用不定义）：
- **附件来源、intake 限制、附件项状态机、处理/落盘通道、重试语义、内建选择器、历史消息图片** → `attachment`（Q-CMP-09 分割线；本面板只渲染「处理中/就绪/失败」的**外观**与入口）。
- **模型胶囊的内容/降级文案/面板本体** → `model`（本面板只给座位与宽度上限 112dp，E-07=A）。
- **灯箱组件本体** → `base.primitives.image-lightbox`；**Toast 本体** → `base.primitives.toast`；**insets 真源** → `base.layout`（E-02=A，本面板**不读** `WindowInsets.ime`）；**圆角/阴影/颜色 token** → `base.theme`。
- **列表底部留白、回到底部按钮的位置** → `chat`（本面板只发布高度；`chat.list.to-bottom` 自己取 `H + 16dp`，见 §1.1）。
- **忙时发送默认行为设置项** → `settings`（首版只有「生成中发送行为：排队」一个取值、作为**占位**；**不暴露 steer 选项**；节点 ID 以 settings 面板 spec 为准）。本面板只消费其值。

**明确不做**（P2 §4 共 12 条，一行摘要，实现时不得"顺手做了"）：`workspace-chip`；手机统计胶囊/报表/到边锁；文档级拖放 DropOverlay；隐藏 `<input type=file>`（能力不丢，形态归 M5）；桌面键盘加速键（Ctrl/⌘）与硬件 Enter 发送；slash 钻取 `drill` 与面包屑 `crumb`；`popupSelect` 命令弹窗（`.popup/.row/.retry/.confirmation`）；`+` 作为命令候选菜单；能力/技能钉选标签；附件轨翻页箭头；旧 myco 自有的三源 sheet 本体（入口保留、本体归 M5）；「清空全部附件」（破坏性无撤销）。另：思考/联网 toggle 已移出（C-08/D-12）；语音输入本文件不定义（§5 `P3-CMP-05`）；队列折叠头不做（E-05=C 采太墟独立条形态）；**steer/插话不做**（需 core steering 事件，§5 后续能力）；**`@` 提及首版不做**（无数据源，§3.15）。

## 1. 布局与网格

### 1.1 与容器的关系

| 项 | 契约 | 依据 |
|---|---|---|
| 在 M2 覆盖栈中的位置 | **不是 route、不进栈**：`composer` 是 `chat` 根 route 内容区内的**固定尾**（与 chat 列表同层、上下相邻）。被上层 route 覆盖时随 chat 一起保活/冻结 | D-01；`p2/base.layout.md` §1.3.1/§1.8.2 |
| 布局位置 | **in-flow**：座位在 chat 内容列的底部，由容器（`base.layout.shell` 的底部贴底槽）为它让出位置；**不是 overlay**（G-01 明确"页面内的固定尾本来就占位"） | E-02=A；G-01 边界段；`p2/composer.md` §2.1③ |
| insets | **只消费、不读系统 insets**：容器把 `union(navigationBars, IME, displayCutout.bottom)` 的真源经 CompositionLocal 下发；本面板把它作为**座位下沿的额外高度**，不参与 `H` 的发布值（`H` 只算面板自己的几何），也不做 `imePadding()` | E-02=A；`base.layout` §1.3.2 第 ⑦ 行（"composer 自己不读 `WindowInsets.ime`"） |
| 与 chat 列表 | 竖直相邻：上方 chat 列表、下方本座位。列表 `contentPadding.bottom = 本面板发布的 H + 24dp`（24dp 归 chat，`chat.list` 字段 2）；**回到底部按钮 `bottom = H + 16dp`**（`chat.list.to-bottom` 字段 2，本面板不定义其位置） | `chat.md` §1.3/§3 `to-bottom`；E-02 |
| 宽度 | 座位满宽；卡宽 = chat 内容列宽 = `min(列宽 − 40dp, 752dp)`，水平居中 —— **与列表内容列左右缘对齐**（同一条竖向对齐线） | `chat.md` §1.3（列表内容列同式）；SB 字段 2（DSH 输入卡与列表同列）；我方取值（P4 校准）：宽屏 752dp 上限使输入卡不随窗口无限拉长 |
| 返回语义 | 本面板**无 route**，不参与返回链；候选面板是面板内浮层，返回优先级 = **IME → 候选面板 → chat 浮层 → 栈** 中"候选面板"这一级；队列编辑 Dialog 是 Modal 浮层 | D-01；`p2/base.layout.md` §C.3 |
| z 归属 | 座位本身走布局顺序（无 z）；候选面板 = 本面板 overlay 槽（menu 家族 1100）；队列编辑 Dialog = modal 家族 1000 | `p2/base.layout.md` §C.6 |
| 横屏/宽屏 | 断点归 M2（D-04：`h<480` 强制 COMPACT 单栏）；本面板只做**行数降档**（§1.4）与"与内容列对齐"两件事 | D-04；`GO/` §2.2 字段 10（横屏降行数） |

### 1.4 多行高度与键盘避让（E-06=B 的落地公式）

**规则**：输入区高度上限 **6 行**，可见行数随"键盘上方可用区"降档到 **2–6 行**（dsh-Go 规则 E0），并额外受"卡总高 ≤ 键盘上方可视区 40%"约束。

```
LH     = 24 + Δ                    // Δ = 内容字号 − 16sp
D(n)   = 48 + (n − 1) × LH         // 草稿区高
C(n)   = D(n) + 48                 // 卡高（+ 工具行）
R      = 72  (有轨) / 0
Q      = 8 + min(q,3)×48  (q>0) / 0
H      = (q>0 ? Q + 4 : 0) + R + C(n) + 8      // 发布的座位高（不含系统 insets）

A      = 键盘打开时聊天列表可视高
       = 屏高 − statusBar − 顶栏 − IME − navBar        （由容器下发的 insets 与壳高算）
n_max  = clamp( floor((0.4 × A − 96 − R − (q>0 ? Q + 4 : 0)) / LH) + 1, 1, 6 )
         硬下限 = 1 行；"2 行下限"（dsh-Go）在 0.4×A 装不下 2 行卡时让位给 1 行
```

| 设备档（竖） | 屏 dp | IME | A | 0.4A | 无轨/队列 → n_max | 有轨(72) → n_max |
|---|---|---|---|---|---|---|
| 小屏 360×640 | 640 | 280 | 256 | 102 | **1**（装不下 2 行） | **1** |
| 主流 360×800 | 800 | 300 | 396 | 158 | **3** | **1** |
| 大屏 412×915 | 915 | 320 | 491 | 196 | **5** | **2** |
| 横屏 915×412（D-04 → COMPACT） | 412 | 200 | 108 | 43 | **1** | **1** |
| 竖屏 · 键盘收起 | 800 | 0 | 696 | 278 | **6（绝对上限）** | **6** |

- 依据：`GO/` §2.2 `composer.editor` 字段 10（"可用行数按「键盘上方 40% 高」降到 2–6"，`composer.dart:158-169`）**E0**；`maxLines:6`（`composer.dart:67,482-483`）**E0**；E-06=B。
- 上表 A/IME 取值与"减 96/减 R/Q"为我方取值（**P4 校准**）：dsh-Go 只给了"40% 与 2–6"这条规则，没给逐 dp 公式；P4 需在 360×800 与 412×915 两档真机实测后回填本表。
- **卡总高 ≤ 0.4×A** 是这条规则的本体（不是"6 行"）：6 行只是键盘收起时的绝对上限。
- **横屏不锁方向**；`h<480` 时按 COMPACT 单栏 + 上表降档（`GO/` §2.2 字段 10 有"横屏打字行数降、顶栏让位"E0；让位细节归 M2）。
- **不重挂载**：降档只改 `n_max` 与 `n`，**草稿文本、光标、选区、IME 组字状态一律保留**（E-02 反证：重挂载丢 IME 组字与选区，`SB` 字段 10 "same DOM inert"）。

### 1.5 高度发布契约（同帧生效，禁止帧后 `jumpTo`）

```
data class ComposerMetrics(
  val seatHeight: Dp,   // H（§1.4 公式结果，不含系统 insets）
  val cardTop: Dp,      // 相对座位顶
  val lineCount: Int,   // n（已 clamp）
  val lineCap: Int,     // n_max
  val state: ComposerState,  // idle / running / submitting / processing / locked / offline
)
CompositionLocalProvider(LocalComposerMetrics provides m) { ... }   // 由 composer.input.seat 提供
```

**硬契约（4 条，全部可验收）**：

1. **发布值 = 解析式结果，不是测量结果**：`H` 由 §1.4 公式用 `(n, q, 有无轨, 有无提示条, Δ)` 直接算出，**不得**用 `Modifier.onSizeChanged` 的实测高回写（实测会晚一帧，且回写会形成 ±1dp 抖动环）。`n` 由草稿区的换行行数在同一帧上报（`TextLayoutResult.lineCount` 的首次布局结果），不得由测量高反推。
2. **chat 消费同帧生效**：列表 `contentPadding.bottom` 与 `chat.list.to-bottom` 的 `bottom` 必须在**同一次组合**内读到新 `H`。禁止"先按旧高排版、下一帧再 `jumpTo`/`scrollBy` 追平"（这就是 P2 §2.1②5 点名的"帧后 jumpTo 造成闪动"）。
3. **高度变化只有 3 个来源**：`n`（行数）、`q`（队列条数）、"有无轨/有无提示条"。这三者任一变化都必须在**同一帧**内同时反映到：卡高、工具栏 y、列表 `contentPadding`、回底钮 `bottom`。**非这三者**的一切视觉变化（主键图标切换、禁用色、处理中蒙层、候选面板开合）**一律不得改变 H**。
4. **禁止高度动画**（G-10）：轨/提示条/队列条的出现消失是**瞬时高度切换**，允许 ≤120ms 的**不透明度**过渡；主键图标切换用 160ms `AnimatedSwitcher`（`GO/` §2.2 字段 9 E0，不涉及高度）。

> 实现选型风险：Compose 若无法做到"0 帧差"，须改用容器内自定义 `Layout` 单测量（先量 composer、再带 padding 量列表）；这条属实现选型，已登记 §5 `P3-CMP-07`（不阻塞，但**验收判据不变**）。
