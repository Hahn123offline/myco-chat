# Bug 台账

> 偶发/稳定 bug 一律登记在此，不进聊天记录就丢。
> 每条：现象 → 复现步骤 → 触发条件 → 影响面板 → 定位（文件:行 或 推测标 E2）→ 状态。
> **禁止**只写"偶发崩溃"。

## 模板

```
### BUG-序号 一句话现象
- 影响面板：
- 复现步骤：
- 触发条件（频率、网络、机型、状态）：
- 定位：文件:行 / 未定位
- 猜测（标 E2，仅记录不作依据）：
- 状态：待复现 / 已复现待修 / 修复中 / 已修（commit）
```
