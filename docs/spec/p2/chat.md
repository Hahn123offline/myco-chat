| 已完成轮默认态 | 过程折叠（控制条收起后成员 `display` 隐藏，`C/ChatNodeSeat.tsx:109`） | 先展开再自动收成摘要（settle，`go/turn_process.dart:193-218`） | 轮折叠条**默认关闭**（`tx/RoundCollapse.kt:77-91`） | 过程区默认展开 | 旧 UI 流式结束**自动展开**（`CC:563-566`）；M5 默认折叠 | **默认折叠**（见 `C-M3-01`）；settle 不做（G-10） |

**结论（任务点 1 的答案）**：myco 采用 DSH `process-groups.ts` 的**段模型**——一轮可有多段「过程组」（连续过程成员为一段），
`user / turn-error / turn-max-tokens / turn-trigger / turn-tail` 出现即 flush 成独立根；最终回答先 flush 再独立；
`turn.process-control` 锚在第一段过程之前、折叠整轮所有过程段。
**反证**：① 若正文也进组，用户折叠过程会把答案一起藏掉 → 找不到回答（DSH 专门先 flush，`N/process-groups.ts:168-172`）；
② 若错误行进组，失败原因被折叠 → 用户只看到"空回复"（dsh-Go 因此规定停止/出错轮不折叠，`go/chat_rows.dart:126-127`）；
③ 若整轮只做一个组、正文塞组内，则"组内 6px / 回复前后 12px"的阅读节奏失效（DSH 间距规则的前提就是正文独立）。
