# 节点 13 字段定义 + 金标准样本

> 一个「节点」= 一个可点 / 可滚 / 可展开 / 可长按的原子交互单元。
> **一个节点必须写满 13 个字段，缺一个即不合格**，不允许"一句话概括"。
> 格式照抄 §2 金标准样本，P1 并行的 6 路事实库都用这个格式。

## 1. 十三字段

| # | 字段 | 要写到什么程度 | 常见错误 |
|---|---|---|---|
| 1 | **身份与出现条件** | ID、所属面板/区域、父节点、什么数据下才出现、出现几次 | 只写"思考块" |
| 2 | **网格与定位** | 父布局、对齐锚（行首/行尾/居中）、固定尺寸或行高、间距 token、与兄弟的最小间距 | 写"在正文上方" |
| 3 | **命中区** | 精确矩形、是否扩边、物理最小边长、与相邻命中区最小间隔 | 只写"整行可点" |
| 4 | **手势** | 单击/长按/双击/滑动/拖动/滚轮；触发阈值、方向锁、与父滚动的仲裁 | 漏掉长按 |
| 5 | **行为** | 状态迁移前后的完整状态、导航目标、发出的命令、是否幂等、能否撤销 | 写"展开" |
| 6 | **视觉状态** | default/pressed/hover/focus/disabled/selected/live 各自差异 + 转场 | 只写默认态 |
| 7 | **布局占位与展开形态** | 是否参与布局流、占位高度、G-03 三形态之一、展开时**每个兄弟节点**是否位移 | 写"展开显示内容" |
| 8 | **滚动语义** | 谁滚、内滚边界条件、到边后行为（G-04）、锚定元素、吸附 | 写"可以滚动" |
| 9 | **动效** | 进入/退出/形变的属性、曲线、时长、能否中断、中断后停在哪 | 写"有动画" |
| 10 | **边界态** | 空、超长、失败、超时、离线、多语言、大字号、横屏各自表现 | 只写正常态 |
| 11 | **无障碍** | 语义角色、标签、焦点顺序、自定义动作、动态播报 | 漏掉 |
| 12 | **依据** | 逐条 `E0/E1` + `文件:行` / `user` / `真机`；`E2` 不得出现 | 只有一句"参考 DSH" |
| 13 | **反证 + 验收 ID** | 「反过来做会坏在哪」+ 至少一条验收 ID + 验收方式（真机手势/单测/截图比对） | 缺反证 |

**依据级别**：`E0` 源码行/真机/用户拍板（唯一可进实现）· `E1` 文档声称（可进 spec）·
`E2` 推测（禁止，只能进 open-questions）。

## 2. 金标准样本：`chat.msg.thinking-header`

> 本样本全部字段已按 DSH 真实源码取证；**它与 myco 当前实现有 3 处分歧**，
> 已登记 [open-questions.md](open-questions.md) Q-01/Q-02/Q-04。

| # | 字段 | 内容 |
|---|---|---|
| 1 | 身份与出现条件 | `chat.msg.thinking-header`。所属：聊天面板 → 消息轮 `turn` → 过程区。出现条件：该轮存在 reasoning 内容。每轮最多 1 个（多个 reasoning 段合并进同一行标题，正文连续）。轮内位置：在 assistant 正文之前，具体节点序列以 `conversation-nodes/assistant.ts` 为准（**P1 补 E0**）。 |
| 2 | 网格与定位 | 父：`turn` 纵向栈，续行左对齐。折叠态根节点**固定高 `24px + font-delta`**（`dsh ReasoningRow.module.css:6-9`）。行内：图标 14px → 间距 → 标题「思考」→ 2×2px 圆点（左右 margin 8px）→ 摘要（`ReasoningRow.tsx:9`、`module.css:32-39`）。摘要 secondary 字号 13/行高 20（`module.css:44-51`）。展开体左缩进 `22px`＝图标 16 + gap 6，上下 padding 4（`module.css:73-77`）。 |
| 3 | 命中区 | 整行可点（`expandOnRowClick`，`dsh ReasoningRow.tsx:94`）。折叠行视觉高仅 24px，**移动端需扩边到 ≥44dp**：扩边规则见 Q-03。 |
| 4 | 手势 | 单击 = 切换展开。长按/双击/滑动：无自定义（未实现即不绑，**不得继承父级长按**）。与父滚动的仲裁：竖直拖动归外层会话滚动，不视为点击（Web 端 `click` 语义天然如此；Compose 用 `clickable` 的 touch slop）。 |
| 5 | 行为 | `toggle()`：折叠→展开、展开→折叠。状态是**节点本地**的，绑在轮次版本号上：版本前进（该轮被隐藏/重建）→ 自动回折叠（`use-disclosure.ts:11-20`）。幂等，可撤销（再点一次）。 |
| 6 | 视觉状态 | `default`：标题字重 400（`module.css:28-30`）；`running`：`data-state=running`，摘要文字 shimmer 流动（`TextShimmer`）+ 呼吸指示；`settled`：`data-state=ok`，静态文字；`expanded`：`data-expanded`，头部变 sticky 且底色遮挡；`preview 关闭`：隐藏圆点与摘要只留标题（`module.css:68-71`）。**无 hover/focus 特殊样式**（Web 默认）。 |
| 7 | 布局占位与展开形态 | **形态 A：inline-uncapped + sticky header**（G-03）。折叠：`contain: size layout` + 固定高 → 摘要文字变化**不引起任何兄弟重排**（G-02）。展开：根节点**不封顶**随内容长高，下方兄弟（工具行、正文）**整体下移**；头部 `position: sticky; top: 0`（`module.css:15-22`）。**不做内部滚动**。 |
| 8 | 滚动语义 | 展开后内容随**外层会话**一起滚；内层无滚动容器 → G-04 不适用。头部 sticky 吸附在会话视口顶部，`z-index:1` + 页面底色。 |
| 9 | 动效 | **展开/收起无高度动画**——模式切换只切 CSS display，不 unmount 摘要（`ReasoningRow.tsx:38-39` 注释）。持续动效只有两处：运行中摘要文字 shimmer（`TextShimmer`），流式摘要右端 48px 渐隐遮罩（G-05，`module.css:59-66`）。无动画可中断问题。 |
| 10 | 边界态 | 摘要文本：`running` 时取**最后一个已完成段落的第一个非空行**；`settled` 时取**首行**（`ReasoningRow.tsx:11-32,56`）。两者都**删除 `**` 加粗标记**（`:57`）。空摘要 → 整个圆点+摘要隐藏（`:58-59` + `module.css:68-71`）。超长 → 单行 nowrap + ellipsis（静态）/ 渐隐（流式）。reasoning 为空但存在 → 行仍出现（待 P1 确认可否为空）。大字号：跟随 `--dsh-content-font-delta` 同步增高。 |
| 11 | 无障碍 | 运行中输出视觉隐藏文案「正在思考」（`ReasoningRow.tsx:84`，G-08）。行本身是 disclosure：需 `aria-expanded`（由 `DisclosureRow` 提供，**P1 补 E0**）。键盘可展开（Web）。移动端：TalkBack 报「思考，可展开/已展开」。 |
| 12 | 依据 | `E0` `dsh packages/client/ui-chat/src/client/chat/ReasoningRow.tsx:9,11-32,56-57,70-94,38-39,84`；`E0` `ReasoningRow.module.css:6-9,15-22,28-51,59-66,68-77`；`E0` `use-disclosure.ts:11-20`；`E1` 轮内位置（待 `conversation-nodes/assistant.ts`）；`E1` 无障碍 aria（待 `DisclosureRow` 源码）。 |
| 13 | 反证 + 验收 | **反证**：若折叠行不定高（G-02 违反），摘要每帧变化都会让下方正文重排 → 读者视线被逐字推走，等于无法阅读；若展开改为封顶内滚（形态 B），思考正文会被锁在 45% 屏高的小窗里，且与外层滚动争夺手势（G-04），用户永远读不完一条长思考。**验收**：`CHAT-01` 折叠行高度恒定（真机录屏，摘要变化时行顶 y 不动）；`CHAT-02` 展开后头部吸附可随时收起（真机手势）；`CHAT-03` 流式摘要右端渐隐无省略号（截图比对）。 |
