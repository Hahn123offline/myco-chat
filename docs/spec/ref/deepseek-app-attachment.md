## 与 myco 现状的差异（这条是用户点名"缺内建 UI"的参照）

- myco 现在是**系统选择器**三个入口（拍照/相册/文件），选中即落盘，**无最近照片、无多选标记**。
- DeepSeek 的做法是**应用内面板**：先给"最近照片"再给三个来源——把"最常用路径（最近截图的图）"缩短到一次点击。

## 仍需确认（截图无法判定，标 E2 待问，**不得据此实现**）

1. 面板与输入区的关系：是**内联展开**（列表被顶上去、无遮罩）还是**覆盖式 sheet**？
2. 最近照片最多显示几张、是否横向滚动、是否有"全部照片"入口。
3. 多选上限（与消息可发图片数是否一致）与选中后的确认动作（立即入队 / 需再点发送）。
4. 点击缩略图 = 选中加入草稿，还是直接发送？（用户口述是"进入发送队列"）
5. 拍照/相册/文件 三个按钮点击后：系统 picker 还是应用内相册网格。
6. 权限被拒时该面板的引导态。
7. 键盘与面板的互斥关系（打开面板是否收键盘）。
