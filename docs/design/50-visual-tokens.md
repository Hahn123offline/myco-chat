## 3. 发光规则（深色模式）

- 只用于**一个**焦点元素（如当前输入卡片/主按钮外侧），`E09A42` 以 8–16% alpha 的径向/线性渐变出现；
- 禁止作为大面积填充、禁止垫在正文下面、禁止同时出现在多个卡片上；
- 浅色模式不用发光，改用边框/阴影层级表达焦点。

## 4. 基础尺度

| 项 | 值 |
|---|---|
| 间距 | 4dp 网格（4/8/12/16/24/32） |
| 圆角 | 12dp（控件）/ 16dp（卡片）/ 24dp（底部面板） |

| 字体 | 正文 16sp / 辅助 13sp / 标题 20–24sp（具体字族待定；优先系统字体，中文观感先看默认） |

## 6. 实现约束

- Compose 侧 `MycoTheme`（`ColorScheme` + 扩展颜色 `LocalMycoColors`），组件里**禁止硬编码 hex**；
- 深色/浅色/跟随系统三档，跟随系统为默认；
- 对比度不足时优先调文字色，不改色卡整体（色卡是产品气质，文字是可读性）。
