## 0. 全局信息架构（先纠正一个说法）

**抽屉不是"手写的所以有没有都行"——它就是 app 的全局导航组件，永远存在。**
之前说的"fallback"指的不是"没有抽屉的设备"，而是同一组件的**自适应形态**：

| 场景 | 抽屉形态 |
|---|---|
| 手机竖屏 | 覆盖式抽屉（宽 82–85%，右侧露出页面一条边，遮罩压暗） |
| 平板/横屏/多窗口 | 同组件转为**常驻侧栏**（不遮罩、页面宽度自适应）；不是"没有抽屉"，是永不关闭 |
| 深链/通知进入 | 抽屉默认关闭，落在目标会话；返回栈由导航层决定 |
| 无障碍 | 抽屉打开时焦点陷阱在抽屉内，TalkBack 可按"关闭抽屉"操作 |

**返回语义（与参考产品一致）**：
- 抽屉打开 → 返回关闭抽屉；
- 聊天页 → 返回=退出页面（不是"回历史页"）；历史永远在抽屉里；
- 设置子页 → 返回父页；
- 用 AndroidX **PredictiveBackHandler**：手势拖动时抽屉/页面跟随位移并预演，松手提交或取消。

## 2. 关键组件行为细则

### S2 Drawer（最高优先级）
- 打开：汉堡点击；**右缘边缘滑**是否支持是产品选择（Android 上与系统返回手势冲突，建议先只做汉堡+预测返回，边缘滑作为可选开关）→ **决定：MVP 只做汉堡，不做边缘滑**。
- 宽度：82–85%；遮罩可点关闭；打开时聊天页不可交互。
- 内容自上而下：品牌/账户入口（可后置）→ 搜索框 → 筛选 chips（P1）→ 分组列表（置顶/今天/昨天/本周/更早）→ 底部账户/设置区。
- 会话行默认：标题单行 + 右侧时间（今天显示时间，更早显示日期）；选中=整行高亮+左侧色条；未读=圆点；**长按=菜单，⋯=同一菜单**（长按是加速器不是唯一入口）。
- 菜单项：重命名（原位输入，自动聚焦全选）/置顶/取消置顶/归档/删除（4s 撤销）/分享（P1）。
- 删除语义：**软删 → 4s 撤销 → 过期后仍在回收站**（P1 回收站），永久删除需二次确认；不自动把删除改成归档。
- 搜索：输入即搜（防抖 200ms），范围=标题+消息正文+归档；结果显示"会话名 + 命中片段 + 命中角色/时间"，点击跳到该会话并滚动到命中消息（需要后端返回 seq）。
- 数据：`lastMessageAt/preview/pinned/archivedAt/unread/status(filters)`、搜索返回 `seq/role/snippet`。

### C3/C4 助手消息与 Markdown
- **助手消息全宽、无气泡**；用户消息气泡；两者之间有分组间距（同一轮工具过程归组）。
- Markdown 支持集（MVP）：标题、粗斜体、删除线、无序/有序列表（悬挂缩进）、引用、行内代码、围栏代码块（语言标签+复制+横向滚动）、表格（横向滚动）、链接（点击前确认外链）、图片（缩略图→点击大图）。公式/脚注 P2。
- 流式半截 Markdown：按"已闭合块正常渲染，未闭合块降级纯文本"处理；代码围栏未闭合时显示为代码块并标"生成中"。
- 助手消息尾：免责声明一行（P1，可开关）。

### C5/C9/C10 操作条、长按、版本
- 操作条常显（助手消息下）：复制、赞、踩、朗读（P1）、分享（P1）、重新生成、⋯（更多：引用/选择文字/删除此回复）。
- 长按=完整菜单（复制/引用/选择文字/重试/删除版本）；ChatGPT Android 选文字走系统选择菜单，我们也走系统选择。
- 重新生成语义：**同节点新增版本，不丢旧回答**（‹1/3› 切换）；UI 先替换显示 + 显示版本切换器；后端需 messageId/version/activeVersion。
- 编辑用户消息：P1（编辑后重跑=新分支/新版本，旧分支保留）。
- 赞/踩：本地记录（P1 上报），需要消息级反馈存储。

### C6/C7 过程折叠与 footer
- 一轮里模型的多步工具/思考显示为**一个折叠块**："过程 · 3 步"；默认折叠；展开显示每步：思考摘要（如有）、工具名、参数摘要、结果摘要、成功/失败。
- 失败工具：折叠块内标红、不影响最终回答；footer 显示"耗时 1分07秒 · 6 步"（P1 成本）。点 footer 打开步骤面板（M2 sheet）。
- 数据：turnId/messageId、每步 startedAt/finishedAt、tool call/result、reasoning 摘要、finishReason。

### P1 输入区状态机
| 状态 | 主按钮 | 附件 | 说明 |
|---|---|---|---|
| 空输入、未生成 | 语音（P1） | 可点 | 无发送键 |
| 有文字、未生成 | 发送 | 可点 | 多行最高 6 行，超出内部滚动 |
| 生成中、空输入 | 停止 | 可点 | 停止=保留已生成部分（已有） |
| 生成中、有文字 | 停止 + "插话"（P1） | 可点 | 插话/排队 P1 |
- 键盘弹起：内容上移、输入区贴键盘；发送后键盘不收起（参考行为，P1 可调）。
- 草稿：按会话保存输入框文本（P1，本地）。
- 模式 chips（DeepSeek）：深度思考开关、联网搜索开关；开=高亮；需要后端按轮传 thinking/tools 开关（当前全局默认）。
- 附件面板：ModalBottomSheet（与 DSH Go 一致）：最近照片横滑 + 拍照/相册/文件；选择后 chip 显示文件名/缩略图、可删；上传中/失败态；失败不进发送队列。
- 隐私文案：面板内一行"附件只存在本机，发送时才进入模型上下文"（已有）。

### S3 TopBar
- 左：汉堡（聊天页）/返回（设置子页）；中：标题左对齐（单行截断）+ 可选副行（模型/workspace 状态，P1）；右：新建（⊕/✎）、更多（⋯）。
- 抽屉打开时顶栏被遮罩；平板常驻侧栏时顶栏不显示汉堡。
- 标题点击 → 会话详情（重命名/模型/时间），P2。

### T1 Settings
- 布局：顶栏（返回+标题）→ 搜索设置（吸底或顶部，P2）→ 分组卡片：AI（模型/权限/个性化）、能力（联网搜索/图像/语音/插件）、外观（主题/字号）、数据（导出/清空/回收站）、通知、关于。
- 行=左 icon + 标题 + 右值 + ›；开关行用 Switch；危险操作红色+二次确认。
- 现有设置页保留 provider/doctor/常驻，重构为上述分组。

## 3. 需要的后端契约（摘要，详见 backend-feature-gaps.md）

| 组件 | 需要 |
|---|---|
| Drawer/列表 | `lastMessageAt/messageCount/preview/pinned/archivedAt/unread`、置顶/归档命令、分页、`session.updated` 在 turn 结束发 |
| 搜索 | `search{query, filters, cursor}` 返回 `sessionId,seq,role,snippet,at`；FTS/索引 |
| 消息/版本 | `messageId/turnId/version/activeVersion`、`chat.regenerate(messageId)`、`chat.editResend`、`message.feedback` |
| 过程/footer | 事件带 seq/requestId；`turn/end.status`；工具/思考事件可分组；`finishReason`；usage/cost 回放 |
| 输入区 | `thinking/tools` 按轮开关；排队/插话（P1）；语音转写（P1） |
| 附件 | 缩略图/预览查询；分块上传或压缩；上传状态（P1） |
| 通知/深链 | `delivery.new`、会话深链（P1） |

## 4. 组件复用与 UI 架构（纠正"设计会变所以不做组件"）

- 所有组件按**三层**拆：tokens（可变）→ primitives（稳定：Drawer/Sheet/Dialog/Swipe/Menu/SearchBar/Composer）→ domain components（会话行/消息/操作条/附件面板）。
- primitives 独立于视觉风格，**一次做对，后续换皮不动结构**；每个组件配 Compose Preview + 真机截图基线（后续可加 paparazzi 截图测试，P2）。
- 导航：单 Activity + Compose Navigation（或自研栈），抽屉是 shell 的一部分，不随风变。
- 预测性返回：`PredictiveBackHandler` 统一在 shell 层，抽屉/设置子页/聊天退出由导航栈驱动。

## 5. 仍未定/需要验证

1. 助手消息是否永远全宽（我们已选全宽），用户气泡样式（参考产品均为简单卡片，采纳）。
2. 边缘滑抽屉是否支持（建议 MVP 不做，避免与系统返回冲突）。
3. 重新生成选"同节点版本"（建议）还是"新会话分支"（DSH Go）→ **建议同节点版本**，分支 P2。
4. 归档 vs 删除的回收站 UI（P1）是否 MVP 必须 → 建议 P1。
5. 语音输入来源（系统语音识别 vs DeepSeek ASR）→ P1 决定。
6. 平板常驻侧栏阈值（建议宽 ≥600dp）。
